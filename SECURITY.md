# Security policy

**Status:** Prototype. No external audit. Not supported for securing real-value deployments.

If you discover a security issue, contact the repository owners privately using GitHub's **Report a vulnerability** feature if enabled on the eventual hosted repository. Until a secure disclosure channel is configured, do not publish exploit details in a public GitHub issue. The maintainer must configure an explicit security contact before public release.

Covered concerns include malicious input parsing, failure to flag changes, approval bypass, invalid report generation and future RPC/XDR ingestion vulnerabilities.

No security patch SLA or bounty program is offered yet. No claim is made that this tool can prove on-chain authorization or detect all upgrades.
