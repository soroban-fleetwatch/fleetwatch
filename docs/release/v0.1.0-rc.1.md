# FleetWatch v0.1.0-rc.1

**Pre-release. Experimental. Not audited.** Release date: 2026-10-28.

This is the first release-candidate tag of FleetWatch, an off-chain monitor
for Soroban contract fleets that share code through CAP-85 executable
references. It is a source release: build it with the Go version in
`.go-version`. No binaries are attached to this tag.

## What is in it

- Offline snapshot comparison, replay and fleet reports.
- Typed RPC capture and bounded ledger-metadata history with header checks.
- Watched reconstruction from an asserted baseline, per operation.
- Resumable ingestion, a bounded polling worker and a continuous single-host
  `follow` service with archives, restore and compaction.
- Durable alert outbox, HMAC-signed HTTPS webhooks, dead-letter recovery.
- Ed25519 signed approval verification and binding, kept separate from
  unsigned policy matches.
- 27 CLI commands; reference in [docs/CLI.md](../CLI.md).

Full list: [CHANGELOG.md](https://github.com/soroban-fleetwatch/fleetwatch/blob/main/CHANGELOG.md).
