# CAP-85 and SDK reconnaissance

Checked 2026-10-26. This is preliminary S1 research, not a claim of live-chain compatibility.

- Official specification: https://github.com/stellar/stellar-protocol/blob/master/core/cap-0085.md (retrieved from raw.githubusercontent.com). Retrieved header states Final, protocol 28.
- The specification adds `CONTRACT_EXECUTABLE_EXTERNAL_REF`, `ContractExecutableExternalRef`, and `SCV_EXECUTABLE_TAG`. The owner entry is persistent contract data; its value is 32 bytes identifying Wasm. Tag content must be preserved as raw bytes. These are specification facts, not observed chain events.
- Module metadata: https://proxy.golang.org/github.com/stellar/go-stellar-sdk/@v/v0.8.0.info reports v0.8.0, revision `921a5b16af9a72d973ab9ba666e96ad8bf2f6ce4`, timestamp 2026-10-20T21:30:21Z.
- Downloaded with `go mod download -json github.com/stellar/go-stellar-sdk@v0.8.0` using normal Go checksum verification. Module sum: `h1:PU0iM2deEly7qs60BGnm2L+lE3WtrvED3WT/MIjet5A=`. Download is in the environment cache, not yet an application dependency.
- The module declares Go 1.25.0 minimum. Existing application still uses only the standard library and retains its Go 1.23 minimum. Adopting this SDK will require an explicit toolchain/CI minimum update.
- Inspected generated source: `xdr/xdr_generated.go` includes the external-reference struct/union variant; `xdr/scval.go` handles `ScValTypeScvExecutableTag` and `ContractExecutableTypeContractExecutableExternalRef`. Existing SDK tests use `ContractExecutableExternalRef{ExecutableOwner: owner, Tag: tag}`.
- RPC methods are in `clients/rpcclient`, not the root `rpcclient` path. `Client.GetLedgerEntries` and `Client.GetNetwork` exist there. Response structures are in `protocols/rpc`.
